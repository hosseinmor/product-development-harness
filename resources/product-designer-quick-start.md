# Product Designer Quick Start

برای شروع **Design Exploration** بر اساس PRD موجود، این متن را در ChatGPT، Claude یا Agent دیگر استفاده کنید:

```text
برای درخواست زیر با Job Vision Product Development Harness، Design Exploration انجام بده.

https://github.com/hosseinmor/product-development-harness/blob/main/AGENTS.md

Current PRD:
[لینک یا فایل PRD فعلی]

Intent:
[مسئله یا محدوده‌ای که می‌خواهیم طراحی کنیم]
```

اگر طراحی کل PRD مدنظر است، می‌توانید بخش `Intent` را حذف کنید. لینک Figma، Prototype یا Research مرتبط را فقط در صورت نیاز اضافه کنید.

لازم نیست نام محصول، منابع Product Knowledge، Design Language، مراحل Workflow یا دستورهای دسترسی را در Prompt تکرار کنید؛ همه این قواعد در Harness هستند. Agent پس از خواندن فایل‌های الزامی و PRD فعلی، اگر دامنهٔ محصول در PRD صریح و روشن باشد و با درخواست تعارض نداشته باشد، آن را اعلام می‌کند و بدون تأیید دوباره ادامه می‌دهد. اگر دامنه مبهم، متعارض یا غیرقابل دسترسی باشد، سؤال کوتاهی برای تعیین آن می‌پرسد. اگر PRD در دسترس نباشد یا Product Decision مهمی در آن مشخص نشده باشد، باید شکاف را طبق Workflow مطرح کند، نه اینکه آن تصمیم را از طرف PM بگیرد.

برای تصمیم‌های مربوط به رابط کاربری، Agent پیش از درخواست انتخاب مسیر، وایرفریم ساده یا نمایش بصری قابل مقایسه ارائه می‌کند؛ لازم نیست جداگانه درخواست وایرفریم کنید. پس از انتخاب مسیر کاری، نمایش فلو و حالت‌های مهم کامل‌تر می‌شود. گفتگو می‌تواند به گزینه‌های قبلی یا تازه برگردد. وقتی تصمیم‌های اصلی تثبیت و طرح نقد و اصلاح شد، Agent باید پیشنهاد جمع‌بندی و انتخاب طراحی را مطرح کند و تغییرهای لازم PRD را با متن پیشنهادی، دلیل، اثر و تصمیم موردنیاز از PM ارائه دهد. انتخاب طراح به‌تنهایی تصمیم محصول یا مجوز انتشار نیست.

در پاسخ‌های اصلی، Agent باید روشن کند الان کجای مسیر هستیم، قدم بعدی پیشنهادی چیست، چه کسی باید اقدام یا تصمیم بگیرد و خروجی بعدی چه خواهد بود. قبل از همگرایی، تصمیم مهم باقی‌مانده و روش مقایسهٔ آن را مشخص می‌کند؛ بعد از همگرایی، پیشنهاد انتخاب و جمع‌بندی طراحی را می‌دهد؛ پس از انتخاب، نمایش منتخب، جمع‌بندی طراحی و پیشنهادهای لازم PRD را آماده می‌کند. اگر آرتیفکت ذخیره و قابل بررسی باشد، قدم بعدی Design Review + PRD Stress Test است؛ اگر وابستگی یا دسترسی مانع است، همان اقدام مشخص را پیشنهاد می‌دهد. برای کارهای مجاز و قابل انجام، منتظر دستور «ادامه بده» نمی‌ماند.
